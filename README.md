# 🛒 Karibu Groceries LTD

A full-stack Grocery Management System built with 
Node.js, Express, MongoDB, HTML, CSS and JavaScript.

## 🌐 Live Demo
[View Live Site](https://karibugroceriesrushdi.netlify.app)

## 🛠 Tech Stack
- Frontend: HTML5, CSS3, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- Deployment: Netlify

## ✨ Features
- Role-Based Access Control (Admin / Cashier)
- Real-time inventory dashboard
- Product search and filtering
- Shopping basket
- Invoice generation
- Sales reports
- Customer management

## 📁 Project Structure
\`\`\`
Karibu-Grocaries-LTD/
├── backend/        # Node.js + Express API
├── Dashboard/      # Admin dashboard
├── Home/           # Homepage
├── basket/         # Shopping basket
├── signin/         # Authentication
├── img/            # Images
└── index.html      # Entry point
\`\`\`

npm install
